About EcoForecast

Making energy data meaningful

A machine learning project that studies past household electricity usage to estimate upcoming consumption.

From historical readings to useful insights

EcoForecast uses historical household electricity consumption data to identify patterns over time. Time-based features and previous readings help a machine learning model estimate near-term energy usage.

The project explores how forecasting can support energy awareness, planning, and data-driven decision-making.

  • ✓ Analyze historical electricity usage
  • ✓ Explore time-based consumption patterns
  • ✓ Generate a one-hour-ahead estimate
